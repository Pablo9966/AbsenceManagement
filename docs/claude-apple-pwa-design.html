Motion Principles
Response Entry

Send button uses spring physics. Feels physical, like pressing a real key. Borrowed from Apple's keyboard.

staggered · 60ms offset

Design DNA

  • Obsidian base, never pure black. Depth without aggression.
  • Glass morphism with restraint: blur only where hierarchy demands it.
  • Clay warm as the human signal in a cold system.
  • Serif display type for emotional weight; geometric sans for function.

What It Takes From Each

  • From Claude: warm amber palette, intellectual tone, flowing conversation rhythm.
  • From Apple: hardware-grade radius precision, Dynamic Island framing, spring physics, spatial audio metaphors in motion.
  • Neither: no purple gradients, no SF Symbols overuse, no chatbot bubble kitsch.

Anti-Patterns

  • No loading spinners. Use skeleton shimmer or nothing.
  • No modal alerts. Inline contextual feedback only.
  • No hamburger menus. Bottom tab bar or gesture-first navigation.
  • No border-radius below 12px on interactive surfaces.
